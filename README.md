# Калькулятор пищевой ценности рецептур

Веб-приложение для расчёта пищевой ценности рецептур: сырьё и готовый продукт, макро- и микронутриенты, углеводный, аминокислотный и жирнокислотный состав, показатели качества белка и жира, маркировка по ТР ТС 022/2011.

## Файлы

- `index.html` – приложение (разметка, стили, расчёты)
- `db.js` – основная база: 405 видов сырья с русскими названиями
- `usda_full.js` – расширенная база USDA (8 058 продуктов, названия на английском), подгружается по кнопке
- `.nojekyll` – отключает обработку Jekyll на GitHub Pages

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите все файлы в корень ветки `main`.
2. Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Приложение работает и локально: откройте `index.html` в браузере.

## Источники данных

- Состав продуктов: USDA National Nutrient Database for Standard Reference, выпуск 26 (общественное достояние)
- Потери белков, жиров, углеводов: обобщённые величины по Скурихину (МУ 4237-86)
- Сохранность по способам обработки: USDA Table of Nutrient Retention Factors, выпуск 6
- Нормы: ТР ТС 022/2011, МР 2.3.1.0253-21; эталоны белка ФАО/ВОЗ

Расчёт не заменяет лабораторные испытания готового продукта.
